# Fitness Hub 0.3.12 — functional test candidate

Pre-alpha candidate for controlled functional testing. Package unchanged. Public TEST-ONLY signing key unchanged. Database schema 9.

## Included

- one canonical body repository shared by Dashboard, Body, Insights and raw weight export;
- exact Health Connect weight/body-fat record IDs and timestamps;
- conservative event deduplication: recency wins across distinct events; source priority cannot make an old record become the latest;
- manual weight/body-fat entry with explicit timestamp, validation, local persistence and source=MANUAL, usable without Health Connect or BLE;
- Source Center, Health Connect permission/status diagnostics and actually observed source packages;
- local/skippable onboarding;
- interactive charts with range and selected value/source detail;
- meal-day navigation and explicit per-100g/per-serving nutrient basis;
- encrypted backup/restore covering 22 domain tables and canonical raw-weight CSV export;
- receive-only BLE fallback without BLUETOOTH_CONNECT.

## Deliberately unavailable

- Xiaomi real login remains blocked by the private-signing gate;
- this candidate requests no INTERNET permission: Open Food Facts network lookup and AI network providers are disabled in the UI/runtime;
- no direct Mi Fitness or Google Fit login is claimed; records are read only when actually exposed through Android Health Connect.

## Verification boundaries

Automated CI verifies Room migrations, repositories, parsers, reconciliation, backup/restore, Compose semantics/layout configurations, lint, APK build, test certificate and checksum.

Pixel screenshot QA could not be completed in the current environment. Real Compose `captureToImage` was attempted in GitHub Actions with both default and native Robolectric rendering and timed out in runs 37847324194 and 37847946367. No screenshots were fabricated. Physical Redmi/S400/Mi Band/account/camera/phone-to-phone tests remain required.
