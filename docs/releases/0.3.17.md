# Fitness Hub 0.3.17 — private Xiaomi login and launcher
- New original FH black/lime adaptive launcher icon, including monochrome resource.
- Release-only INTERNET permission and real publisher gate: exact approved certificate, package and non-debuggable APK.
- Existing direct Xiaomi login, explicit region/person/device selection, history import, cancellation and local archive are now reachable in the approved private release.
- Public TEST/debug APK remains offline and blocked for real credentials.
- Passwords are entered by the owner on the phone, never in chat or CI. Sessions stay in encrypted on-device no-backup storage.
- Experimental unofficial vendor adapter; CAPTCHA/additional verification is detected but continuation is unsupported. No live account, firmware or hardware Keystore test has been performed.
- This release uses the same package with a new certificate. Android requires removing the old TEST app before installation; the owner approved disposable test data, but removal is not performed automatically.
- Private APK signing/publication is separately gated by verified pipeline setup and owner review. CI outcome and actual artifact must be checked before claiming availability.
