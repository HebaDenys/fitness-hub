# Fitness Hub 0.3.5 — Xiaomi source screen

Pre-alpha test build. Same application ID, test certificate and database schema 6.

## Added

- Settings -> Xiaomi Home route with local source status and archived-record details.
- Explicit region/model selection and paged discovery of people/devices observed in authorized history.
- Two-step person/device confirmation, current-session recheck and existing immutable Room ownership guard.
- Singleton Hilt runtime/repository connecting UI to authentication, discovery, saved binding and manual history import.
- Manual continuation/cancellation and logout that retains stored health data.
- Paginated offline history, per-metric source method/unit/quality and honest snapshot counts.
- Masked, non-saveable credential fields and secure-window lifecycle handling.
- Discovery, native Room, ViewModel and Compose UI tests with synthetic data.

## What is available in this APK

Open Settings -> Xiaomi Home. The screen shows the private-signing block and local archive status. It does NOT accept real Xiaomi credentials in the current publicly signed build. The normal account/discovery/confirmation path is implemented behind the existing gate and verified with synthetic tests; it is not claimed as a working login on the user's phone.

No second APK, root, external SmartScaleConnect installation or mandatory CSV was added. Existing CSV/BLE data remains in its existing sections.

## Remaining limitations

Private signing/custody/migration requires owner approval. Real Xiaomi account/model compatibility, challenge completion, periodic sync, canonical cross-source analytics and Health Connect write-back remain incomplete. UI tests are Robolectric, not physical Redmi tests.

Do not uninstall an installation with valuable data. Backup v2 is database-only, same-schema, bounded to 32 MiB plaintext and conservative on conflicts; preferences/media/credentials are not included. This release changes neither signing identity nor database version.
