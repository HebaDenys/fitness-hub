# CI test signing\n\n`fitnesshub-test.jks.b64` is a deliberately public **test-only** Android signing key used for rolling debug APKs. It exists so successive `test-latest` builds can update an installed test APK without uninstalling it.\n\nIt must never be used for a production or Play Store release. Production signing material must remain private and separate.\n\nPublic test credentials: store/key password `fitnesshub`, alias `fitnesshubtest`.\n
